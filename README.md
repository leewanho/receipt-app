# 영수증 정리 — 영수증 찍으면 엑셀

영수증을 찍으면 AI가 날짜·사용처·금액을 읽어주고, 확인만 하면 엑셀 파일이 만들어지는 앱입니다.
(휴대폰 홈 화면에 아이콘으로 설치해서 씁니다)

> 이 글은 **개발을 몰라도** 따라 할 수 있게 썼습니다. 처음 한 번만 하면 됩니다. (약 30분)

---

## 전체 순서 한눈에 보기

1. Gemini 키 만들기 (영수증을 읽는 AI 열쇠, 무료)
2. 프로젝트를 GitHub에 올리기
3. Vercel에 올려서 인터넷 주소 만들기
4. 환경변수(비밀 설정) 넣기
5. 하루 횟수 저장소(Upstash) 연결하기
6. 아버지 휴대폰 홈 화면에 아이콘 넣기

---

## 1단계. Gemini API 키 만들기 (무료)

1. 컴퓨터에서 https://aistudio.google.com/apikey 에 접속합니다.
2. 구글 계정으로 로그인합니다.
3. **API 키 만들기(Create API key)** 를 누르고, 만들어진 긴 글자(`AIza...`)를 복사해 메모장에 붙여 둡니다.
4. 이 글자는 **비밀번호와 같습니다.** 카톡·메일·사진으로 남에게 보내지 마세요.

> ⚠️ **알아두세요 (개인정보)**: 구글 문서에 따르면 무료 등급으로 보낸 내용은 구글이 서비스 개선에 사용할 수 있다고 되어 있습니다.
> 영수증에는 사업자번호·카드사 정보 등이 찍혀 있으니, 민감한 영수증이 많다면 유료 전환(아래 "비용" 참고)을 고려하세요.

---

## 2단계. GitHub에 프로젝트 올리기

1. https://github.com 에서 가입·로그인합니다.
2. 오른쪽 위 **+ → New repository** → 이름 `receipt-app` → **Private** 선택 → **Create repository**.
3. 만들어진 화면에서 **uploading an existing file** 링크를 눌러, 이 프로젝트 폴더의 파일들을 끌어다 놓습니다.
   - 올리지 말 것: `node_modules` 폴더, `dist` 폴더, `.env` 파일 (비밀이 들어 있습니다)
4. **Commit changes** 를 누릅니다.

---

## 3단계. Vercel에 올리기

1. https://vercel.com 에서 **Continue with GitHub** 로 가입합니다. (무료 Hobby 플랜)
2. **Add New → Project** → 방금 만든 `receipt-app` 옆 **Import**.
3. 설정은 그대로 두고 **Deploy** 를 누릅니다. (Framework는 Vite로 자동 인식됩니다)
4. 1~2분 뒤 `https://receipt-app-xxxx.vercel.app` 같은 주소가 생깁니다. 아직은 4단계 전이라 영수증 읽기가 안 됩니다.

---

## 4단계. 환경변수 넣기

Vercel 프로젝트 화면 → **Settings → Environment Variables** 에서 아래를 하나씩 추가합니다.

| 이름 | 넣을 값 | 설명 |
|------|---------|------|
| `GEMINI_API_KEY` | 1단계에서 복사한 키 | 영수증 읽는 AI 열쇠 |
| `APP_PIN` | 예: `4821` | 사용자가 처음에 한 번 누를 4자리 비밀번호. `1234` 같은 쉬운 번호는 피하세요 |
| `DAILY_LIMIT` | `60` | 하루에 읽을 수 있는 최대 장수 |
| `OCR_PROVIDER` | `gemini` | 기본 AI. 나중에 `claude`로 바꾸면 유료 AI로 전환 |
| `GEMINI_MODEL` | (선택) 예: `gemini-3.6-flash` | 모델 이름이 바뀌거나 단종될 때만 수정 |

값을 모두 넣었으면 **Deployments → 맨 위 항목 ⋯ → Redeploy** 를 눌러야 적용됩니다.

### (선택) 한도가 차면 자동으로 유료 AI로 넘어가게 하기
- `ANTHROPIC_API_KEY` : https://console.anthropic.com 에서 발급한 키
- `OCR_FALLBACK_PROVIDER` : `claude`
- 비워 두면, 한도가 찼을 때 "잠시 후 다시 눌러주세요"만 표시됩니다.

---

## 5단계. 하루 횟수 저장소 연결 (꼭 하세요)

하루 사용 횟수를 기억해 두는 무료 메모장입니다. **연결하지 않으면 영수증 읽기가 막힙니다** (제한이 안 걸린 채로 열려 있는 것을 막기 위해서입니다).

1. Vercel 프로젝트 화면 → **Storage** 탭 → **Marketplace에서 Upstash (Redis)** 선택 → **Free** 플랜으로 만들기.
2. 만들 때 이 프로젝트에 **Connect** 하면 필요한 설정이 자동으로 들어갑니다.
3. 다시 **Redeploy** 합니다.

---

## 6단계. 휴대폰에 아이콘 넣기

휴대폰으로 3단계의 인터넷 주소를 엽니다. (문자·카톡으로 주소를 보내 두면 편합니다)

**아이폰 (반드시 Safari로)**
1. 아래 가운데 **공유 버튼(네모에 화살표)** 누르기
2. **홈 화면에 추가** 누르기 → **추가**

**안드로이드 / 갤럭시 (크롬)**
1. 오른쪽 위 **점 세 개(⋮)** 누르기
2. **앱 설치** 또는 **홈 화면에 추가** 누르기 → **설치**
3. 삼성 인터넷을 쓰는 경우: 오른쪽 아래 **≡ 메뉴 → 현재 페이지 추가 → 홈 화면**
4. 카카오톡 안에서 주소가 열렸다면 **크롬으로 다시 열기**를 한 뒤 위 순서대로 하세요.

이제 홈 화면의 **영수증** 아이콘을 누르면 앱처럼 열립니다. 처음 영수증을 읽을 때 4자리 비밀번호를 한 번 누르면 기억합니다.

## 사용자가 쓰는 방법

1. **📷 영수증 찍기** (또는 **🖼 사진에서 고르기**, 여러 장 선택 가능)
2. 화면의 값이 맞는지 보기. 노란 칸은 AI가 자신 없는 칸이니 꼭 확인. 틀리면 눌러서 고치기 → **저장**
3. **📋 저장한 영수증 보기** → **📥 엑셀로 받기** → 기간 고르기 → **💬 카톡 등으로 보내기**

## 내 컴퓨터/휴대폰에서 먼저 테스트하기

컴퓨터에 [Node.js](https://nodejs.org) (LTS 버전)를 설치한 뒤, 프로젝트 폴더에서 터미널을 열어 실행합니다.

```bash
npm install
```

1. `.env.example` 파일을 복사해 `.env.local` 로 이름을 바꾸고 `GEMINI_API_KEY`, `APP_PIN` 을 채웁니다.
2. 아래를 실행합니다. Vercel 로그인은 필요 없습니다.

```bash
npm run dev
```

3. 터미널에 나오는 `Network: http://192.168.x.x:5173` 주소를 **같은 와이파이에 연결된 휴대폰**에서 엽니다.
   - 영수증 읽기까지 동작합니다. (로컬 테스트에서는 하루 횟수 저장소 없이도 됩니다.)
   - 윈도우 PC는 네트워크가 **개인 네트워크**여야 휴대폰에서 접속됩니다. (설정 → 네트워크 및 인터넷 → 이더넷/Wi-Fi → 네트워크 프로필 유형)
   - `http` 주소에서는 홈 화면 설치와 카톡 공유가 되지 않습니다. 이 둘은 배포 후(`https`)에 확인하세요.

> `npx vercel dev`는 `.env.local`을 서버 기능에 전달하지 않아서 이 프로젝트의 로컬 테스트에는 쓰지 않습니다.

**배포할 때 (Vercel 로그인 후)**

```bash
npx vercel deploy --prod --yes
```

실제 영수증으로 확인할 체크리스트는 [tests/receipt-cases.md](tests/receipt-cases.md) 에 있습니다.

## 비용·한도 (확인일: 2026-10-27, 공식 문서 기준)

### Gemini 무료 등급
- 공식 가격 페이지에 Flash 계열(예: `gemini-3.6-flash`, `gemini-3.5-flash-lite`)이 무료 등급으로 표시됩니다.
- **하루 몇 장까지인지는 공식 문서에 숫자가 없습니다.** 구글은 "AI Studio 화면에서 내 프로젝트의 한도를 확인하라"고만 안내하고, 한도는 프로젝트별이며 **하루 한도는 태평양 시간 자정(한국 시간 오후 4~5시 무렵)에 초기화**됩니다.
- 인터넷의 정리글들은 숫자가 제각각이고(분당 5~15회, 하루 약 20~1,500회), 2026년 들어 줄었다는 글도 있어 믿기 어렵습니다.
- 그래도 **월 100장 정도**(하루 3~5장)는 가장 보수적인 수치로도 무난히 들어갈 것으로 보입니다. 정확한 수치는 https://aistudio.google.com 의 사용량(Usage/Rate limit) 화면에서 직접 확인하세요.

### 유료로 전환할 때 (모두 100만 토큰당 가격, 공식 가격표)

| AI | 입력 | 출력 |
|----|------|------|
| Claude Haiku 5.5 (`claude-haiku-5-5`) | $0.10 | $0.50 |
| Gemini 3.6 Flash (유료) | $0.75 (2027-01-01부터 $1.50) | $3.75 (2027-01-01부터 $7.50) |

**영수증 1장 예상 비용 (추정치)**: 사진 1장을 약 3,000~3,500 입력 토큰(사진 + 지시문), 읽은 결과를 약 500 출력 토큰으로 가정했습니다. 사진 토큰 수는 공식 문서를 확인한 값이 아니라 일반적인 계산에 따른 **추정**입니다.

| AI | 1장 | 월 100장 | 원화 (1달러≈1,400원 가정) |
|----|-----|----------|---------------------------|
| Claude Haiku 5.5 | 약 $0.0006 | 약 $0.06 | **월 약 80~100원** |
| Gemini 3.6 Flash (유료) | 약 $0.003~0.004 | 약 $0.3~0.4 | 월 약 500원 (2027년부터 약 2배) |

→ 월 100장이면 유료로 바꿔도 **한 달에 커피 한 잔 값이 안 됩니다.** 전환은 Vercel 환경변수 `OCR_PROVIDER=claude` 와 `ANTHROPIC_API_KEY` 만 넣고 Redeploy 하면 됩니다. 코드 수정은 필요 없습니다.
(정확한 최신 가격은 https://platform.claude.com/docs/en/about-claude/pricing 에서 확인하세요.)

Vercel(무료 Hobby)과 Upstash(무료)는 이 정도 사용량에서 비용이 들지 않습니다.

## 문제가 생겼을 때

| 증상 | 해결 |
|------|------|
| "비밀번호가 맞지 않아요" | 앱 ⚙ 설정 → 비밀번호 다시 입력하기. Vercel의 `APP_PIN` 값과 같아야 합니다 |
| "잠시 문제가 생겼어요" | `GEMINI_API_KEY`가 맞는지, 5단계(Upstash 연결) 후 Redeploy 했는지 확인. Vercel → Logs 에서 원인 확인 |
| "오늘은 여기까지예요" | 하루 제한(`DAILY_LIMIT`)에 도달. 내일 되거나 값을 올리세요 |
| "지금 사람이 많아요" | 무료 한도가 찬 것. 잠시 후 다시. 자주 나면 유료 전환 |
| 폰을 바꿨어요 / 데이터가 걱정돼요 | ⚙ 설정 → 백업 파일 받기, 새 폰에서 백업 파일 불러오기 |

> 영수증 데이터는 **그 휴대폰 안**에만 저장됩니다. 앱을 지우거나 브라우저 데이터를 지우면 사라지니, 가끔 **백업 파일 받기**를 해두세요.

## 개발자용 메모

- 프론트: React + Vite + TypeScript + PWA, 저장은 IndexedDB(`idb`), 엑셀은 ExcelJS(버튼을 누를 때만 불러옴)
- 서버: `api/ocr.ts` (Vercel Function). AI 호출은 `api/_lib/providers/` 의 `OcrProvider` 인터페이스 뒤에 있고, 429·시간 초과 시 `OCR_FALLBACK_PROVIDER` 로 자동 재시도
- 테스트: `npm test` (자동 테스트 34개), 타입 검사: `npm run typecheck`
- PIN 검사는 `api/_lib/auth.ts` 한 곳에 모여 있어, 나중에 시도 횟수 제한을 붙이기 쉽습니다
